# QA Scaffolding service and project images

Upload owner-approved service/project photographs here on preview/qa-scaffolding. Use descriptive filenames, ideally lowercase with hyphens, for example service-name-01.webp. JPEG and WebP are suitable for photographs.

Supply the relevant service/project name with each image. Do not assume an example image shows completed QA work unless confirmed. Upload only permissioned images. These files will be connected to the webpage after upload.
