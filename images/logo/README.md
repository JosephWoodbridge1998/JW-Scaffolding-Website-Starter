# Business logo

Upload the business's approved logo here, preferably as SVG, transparent PNG or WebP. Use simple filenames such as business-logo.svg or business-logo.png.

For a specific prospect, switch to its preview/company-name branch before uploading. Keep main as the generic starter; do not put a prospect's branding into main unless intentionally updating the base.

Uploading an image does not automatically display it on the website. Update index.html to reference the approved file and add appropriate alternative text. Do not upload confidential assets to a public repository.
